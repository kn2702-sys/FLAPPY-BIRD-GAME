# 🐦 Flappy Bird Game

A modern browser-based recreation of the classic **Flappy Bird** game, built using modern web technologies. The game delivers smooth gameplay, responsive controls, real-time score tracking, and an engaging user experience across desktop and mobile devices.

---

## 🎮 Live Demo

🔗 **Play Now:** https://bird-game.space-z.ai/

---

## 📖 Overview

Flappy Bird Game is a lightweight browser game inspired by the classic arcade experience. The objective is simple: navigate the bird through incoming pipes without colliding while achieving the highest possible score.

This project demonstrates game development fundamentals such as animation loops, collision detection, state management, event handling, and responsive user interface design. :contentReference[oaicite:0]{index=0}

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/kn2702-sys/FLAPPY-BIRD-GAME.git
```

### Navigate to the Project

```bash
cd FLAPPY-BIRD-GAME
```

### Install Dependencies

```bash
npm install
```

or

```bash
bun install
```

### Run the Development Server

```bash
npm run dev
```

or

```bash
bun dev
```

Open your browser and visit:

```
http://localhost:3000
```
